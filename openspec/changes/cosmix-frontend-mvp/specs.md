# Specifications

## Functional Specs

### FS-001: AI 流式生成

**触发条件**: 用户点击"开始创作"按钮

**前置条件**:
- 已输入创作想法 (至少 2 个字符)
- 已选择模板
- 无正在进行的生成任务

**行为**:
1. 按钮显示 loading 状态，禁用点击
2. 建立 SSE 连接到 `/api/v1/generate`
3. 实时接收 token 并渲染到 StreamingText 组件
4. 生成完成后播放音效，显示完成动画
5. 内容自动填充到编辑器

**异常处理**:
- 网络超时 (30s): 显示错误提示，允许重试
- API 错误: 显示友好错误信息
- 用户中断: 保留已生成内容

---

### FS-002: 草稿自动保存

**触发条件**: 编辑器内容变化

**行为**:
1. 内容变化后启动 1 秒 debounce 计时器
2. 计时器结束后保存到 localStorage
3. 显示"已保存"状态指示

**存储格式**:
```json
{
  "cosmix_drafts": [
    {
      "id": "uuid",
      "title": "自动提取或用户输入",
      "content": "<html>...</html>",
      "templateId": "campus-revenge",
      "createdAt": "2026-02-05T10:00:00Z",
      "updatedAt": "2026-02-05T10:05:00Z"
    }
  ]
}
```

**限制**:
- 最多保存 10 篇草稿
- 超出时删除最早的草稿
- 单篇最大 50KB

---

### FS-003: 一键复制

**触发条件**: 用户点击"复制"按钮

**行为**:
1. 默认复制富文本格式 (保留格式)
2. 长按或右键可选择纯文本模式
3. 复制成功后显示绿色闪烁动画
4. 显示 Toast 提示"已复制到剪贴板"

**技术实现**:
- 使用 Clipboard API
- 富文本使用 `text/html` MIME type
- 纯文本使用 `text/plain` MIME type

---

### FS-004: 暗黑模式

**触发条件**:
- 用户点击主题切换按钮
- 用户按下 Cmd+D

**行为**:
1. 切换 `dark` class 到 html 元素
2. 持久化选择到 localStorage
3. 首次访问跟随系统偏好

**样式变化**:
- 背景: #FFFFFF → #0F0F0F
- 文字: #111827 → #F9FAFB
- 强调色保持不变

---

### FS-005: 快捷键

| 快捷键 | 功能 | 条件 |
|--------|------|------|
| Cmd+G | 生成内容 | 输入框有内容且未生成中 |
| Cmd+C | 复制内容 | 编辑器有内容 |
| Cmd+S | 保存草稿 | 编辑器有内容 |
| Cmd+Z | 撤销 | 编辑器有历史 |
| Cmd+D | 切换暗黑模式 | 任何时候 |

**冲突处理**:
- 在输入框聚焦时，Cmd+C 保持系统默认行为
- 快捷键使用 `event.preventDefault()` 阻止默认行为

|------|------|---------|
| LCP | < 2.5s | Lighthouse |

### 颜色规范

- 主色 (Primary): `#8B5CF6` - 按钮、链接、强调
- 辅色 (Secondary): `#06B6D4` - 次要信息、图标
- 强调色 (Accent): `#F59E0B` - 热门标签、警告

### 间距规范

- 页面边距: 24px (mobile: 16px)
- 组件间距: 16px
- 组件内间距: 12px

### 动画规范

- 过渡时长: 200ms
- 缓动函数: ease-out
- 生成完成震动: 5ms
